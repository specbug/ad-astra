# Gaia-informed TGLC reduction of TIC 201308024

The declared S1/S2 TGLC comparison strengthens the follow-up case for variability associated with TIC 201308024 (Gaia DR3 4906011953900670976). It does not establish a new object, a physical period, an unresolved companion, or discovery significance. These are alternative reductions of the same TESS full-frame images, not independent telescope observations.

TGLC uses Gaia DR3 priors and an effective PSF forward model to remove neighboring-star contributions. Public native-v1 target products were selected from the saved complete MAST metadata, and a declaration fixing sectors 1/2 and periods 2.03270208338902 and 4.194743460281676 days preceded product downloads and fitting. No later-sector flux or additional period search was used.

## Results

All amplitudes below are relative semiamplitudes in ppm after median normalization. Each fixed-frequency sinusoid includes separate offsets and slopes for segments split by gaps longer than 0.5 days. Ordinary and Huber-2.5 regressions use no borrowed cadence uncertainties or clipping. Values are descriptive, without false-alarm probabilities.

The S2 4.19-day signal survives both raw Gaia-informed PSF and aperture extractions and ordinary/robust fitting, with closely matching phases at the fixed reference epoch. This supports the signal being associated with the modeled target rather than straightforward contamination from a Gaia-resolved neighbor. The S1 2.03-day modulation remains substantial in both raw extractions; the 4.19-day S1 fit is sensitive to robust weighting. These results do not imply one coherent astrophysical clock across both sectors. Unmodeled image systematics, Gaia-unresolved sources, and assumptions in the forward model remain possible.

The FITS headers explicitly declare producer calibration using a 1-day biweight detrending window. Calibrated flux columns are near-unity normalized curves, despite native-v1 calibrated-error header comments describing e-/s. They are therefore compared as relative ppm, without using those header scatters as independent measurement errors. The much smaller calibrated amplitudes cannot invalidate the raw multiday signals: the calibration changes their transfer function, which we have not quantitatively measured through injection/recovery. Likewise, ordinary/robust disagreement in S1 calibrated fits cautions against overinterpreting their residual oscillations.

The native background column has robust amplitudes 0.88/0.37 e-/s at the two periods in S1 and 0.05/0.09 e-/s in S2. Its additive locally modified background offset does not change fixed-frequency amplitudes. There are no time-dependent centroid columns in these products; static STAR_X/STAR_Y values do not furnish a centroid-period test.

## Native format and integrity

Both files identify the exact TIC and Gaia source, with S1 camera 3/CCD 1 and S2 camera 3/CCD 2. TIMEUNIT=d, TIMESYS=TDB, TIMEREF=SOLARSYSTEM and BJDREFI+BJDREFR=2457000 explicitly establish the native BTJD convention. Usable rows require both TESS_flags == 0 and TGLC_flags == 0, applied elementwise, with finite time and flux. This yields 1267 of 1282 rows in S1 and 907 of 1245 in S2. Stable time sorting and first duplicate-time retention are recorded in the reader; negative flux values are not silently clipped.

The generic ArchiveClient structurally validates original FITS bytes and checks supplied CHECKSUM/DATASUM cards. These two publisher files provide neither checksum card, so local SHA256 protects subsequent identity but does not provide an independent publisher checksum. Download URI, final URL, timestamps, sizes and SHA256 live beside each original file in data/tglc-201308024/cache. No failed requests occurred in this reduction.

Authoritative product-format evidence comes from the downloaded FITS headers and [official MAST README](https://archive.stsci.edu/hlsps/tglc/hlsp_tglc_tess_ffi_all_tess_v1_readme.txt), retained locally with provenance. Current upstream source snapshots are supplementary documentation, not an assertion that current main is the exact software release that produced these archived v1 products. In particular, current code adds newer flags and corrected scatter descriptions; those are not retroactively imposed on these native products. A downloaded plotting example contains Python list `and` expressions for flag selection; our reader uses explicit elementwise conjunction instead.

Sources: src/adastra/tglc.py and scripts/tglc_201308024.py; six tests in tests/test_tglc.py guard missing/wrong native time conventions, Gaia identity, independent quality masks and accidental later-sector access.
